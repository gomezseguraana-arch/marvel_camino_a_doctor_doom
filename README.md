ORDEN PARA DOOMSDAY — PÁGINA WEB

Contiene 16 títulos (17 casillas: Loki T1 y T2 por separado)..

PARA ABRIR
1. Abrí index.html en tu navegador.
2. Marcá películas y series como vistas. El progreso se guarda automáticamente en este navegador.
3. Para cambiar de dispositivo o navegador, usá «Guardar copia» e «Importar».


IMPORTANTE
El progreso se guarda por navegador y origen web (localStorage), no en una cuenta.
Al cambiar la dirección de la web o usar otro dispositivo, podría requerirse importar el respaldo.
La imagen de cabecera requiere conexión a Internet.
Sitio de fans, no oficial de Marvel o Disney.
